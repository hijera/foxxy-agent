Where the fork is headed. This is a direction, not a commitment: scope and ordering may change.
Items marked **(?)** are still under discussion and not decided yet.

- Fix Windows-specific issues
- SVN support on par with git
- Native IDE integration on par with Kilo Code
- Repository layout for the IntelliJ plugin
- Assistant mode

- Session export and import
- Per-project settings (?)
- Loop protection
- Tool auto-repair
