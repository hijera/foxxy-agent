# FoxxyCode Roadmap

Where the fork is headed. This is a direction, not a commitment: scope and ordering may change.
Items marked **(?)** are still under discussion and not decided yet. A **✅** marks what has
shipped in full; an item that is only partly there stays unmarked.

A line is the first two numbers of a version: releases `0.3.0`, `0.3.1`, … belong to the 0.3.x
section. The last number grows with every merged change, and the next line starts once its section
is ready (how that works is described in the
[release setup](docs/contributing/release-setup.md)).

## 0.3.x

- ✅ SVN support on par with git
- ✅ A plugin repository for IntelliJ
- ✅ Fix Windows-specific issues
- ✅ Fix session rendering stability issues
- ✅ Debug mode like Kilo Code
- ✅ Asynchronous command execution
- ✅ Subagents

## 0.4.x
